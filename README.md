# The Rental Studio

Sitio web de The Rental Studio: catálogo de piezas de decoración para eventos, montajes y cotización por WhatsApp.

- `index.html` — la página completa (catálogo, cotización y Modo tienda).
- `p/` fotos de productos · `mt/` y `ev/` fotos de montajes.
- `firebase-config.js` — configuración pública de Firebase (inicio de sesión y base de datos de Modo tienda).
- `firestore.rules` — reglas de seguridad de Firestore (se pegan en la consola de Firebase → Firestore → Reglas).
- `vendor/` — librerías de Firebase 10.14.1 (compat).
